# Дневник мигрени для Home Assistant

[English](../README.md) · **Русский** · [Français](README.fr.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Lëtzebuergesch](README.lb.md)

**Migraine Diary** — локальная интеграция Home Assistant для регистрации приступов головной боли и мигрени, симптомов, лекарств и питания. Она фиксирует события, но не ставит диагнозы и не анализирует причины приступов.

## Возможности
- Начало и окончание приступа, исправление времени начала и добавление завершённого приступа задним числом.
- Интенсивность боли, выбор одной или нескольких из 19 зон головы на SVG-схеме, регистрация симптомов и предвестников.
- Учёт лекарств: название, доза, единицы измерения и время приёма.
- Дневник питания: продукт, количество, примечание, время; редактирование и удаление записей.
- История и календарь приступов.
- Три режима карточки: **только мигрень**, **мигрень + питание**, **только питание**. Можно разместить две карточки на одной панели.
- Полная выгрузка CSV без ограничения в 1000 записей; формат UTF-8 с BOM, разделитель `;`.
- Локальное хранение в SQLite, сущности и действия Home Assistant для автоматизаций.

## Установка через HACS
1. Откройте **HACS → ⋮ → Пользовательские репозитории**.
2. Добавьте `https://github.com/immortalserg/ha-migraine-diary` с типом **Integration**.
3. Установите **Migraine Diary** и перезапустите Home Assistant.
4. Перейдите в **Настройки → Устройства и службы → Добавить интеграцию**, найдите **Migraine Diary**.
5. Добавьте карточку на панель управления. JavaScript и SVG подключаются автоматически; отдельный ресурс Lovelace не нужен.

Ручная установка: скопируйте `custom_components/migraine_diary` в папку `<config>/custom_components/` и перезапустите Home Assistant.

## Настройка карточек
Карточка имеет визуальный редактор. Для ручной настройки:

```yaml
type: custom:migraine-diary-card
card_mode: both
profile_id: patient
language: ru
```

Значения `card_mode`: `migraine` — только мигрень, `both` — мигрень и питание, `food` — только питание. Для двух карточек одного дневника укажите одинаковый `profile_id`. Форма питания может быть скрыта отдельно.

## Языки
Английский (`en`), русский (`ru`), французский (`fr`), немецкий (`de`), итальянский (`it`), люксембургский (`lb` / `lu`). В настройках интеграции можно выбрать язык или **Автоматически**; карточка поддерживает собственный параметр `language`.

## Экспорт и автоматизации
Кнопка **Экспорт CSV** выгружает все события. Поля: `date`, `event`, `level`, `zones`, `symptoms`, `medication`, `food`, `quantity`, `notes`, `dose`, `unit`, `episode_id`, `id`. Файл подходит для LibreOffice, Excel и внешних скриптов анализа.

Действия интеграции: `start_episode`, `end_episode`, `record_past_episode`, `correct_active_start`, `record_premonition`, `record_pain`, `record_medication`, `record_food`, `update_food`, `delete_food`, `list_history`, `export_csv` (домен `migraine_diary`). Параметры доступны в **Инструменты разработчика → Действия**.

## Конфиденциальность и поддержка
Данные хранятся локально в Home Assistant. CSV содержит медицинские сведения: защищайте файлы, доступ к системе и резервные копии. Интеграция **не является медицинским прибором** и не заменяет консультацию врача.
